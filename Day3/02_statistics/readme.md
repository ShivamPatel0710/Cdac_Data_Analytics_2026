### Statistics in Data Science
- the science of collecting, organizing, analyzing, interpreting, and presenting data to make informed decisions.
- foundational backbone that transforms raw data into reliable insights, power ML algo and validation predictive models.

### Types of Ststistics
- **Descriptive Statistics:** Summarizes and organises the main features of a dataset using metrics like central tendency (mean, median, mode) and dispersion (variance, stadard deviation, range) to make large of data understandable.
- **Inferential Statistics:** Uses a smaller sample of data to make prediction, test assumptions, or draw conclusion about a larger population.

### Key Statistics Concepts
- **Probability & Distribution:** Model incertainity and predicts the likelihood of future events.
- **Hypothesis Testing :** Evaluate assumptions or compares groups using test like t-tests, ANOVA, and chi-squared tests.
- **Co-relations and Regression:** Measures relationship between variables and forecasts numerical outcomes.
- **Bayesian Statistics:** Incorporates prior domain knowledge to update the probability of a hypothesis as new data arrives.
